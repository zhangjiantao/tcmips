# TCMIPS SDK v2.1.2 Release Notes

- **版本**：2.1.2

## 新功能

- 模拟器新增 **`-mhz=<MHz>` 执行频率上限**（仅 fast 模式），用于近似真实硬件性能量化
- guest 退出时在 stderr 输出 **总指令数**，便于定点 / 软浮点实现对比
- SDL2 支持 **`SDL_RenderSetLogicalSize`** 逻辑分辨率

## 新增库

- **libstb**：stb 单头库集合（image / image_resize2 / truetype / ds / sprintf / rect_pack）
- **libfixmath**：Q16.16 定点数学库，无 FPU 目标上较软件浮点约快 2 倍

## 优化

- SDL1 / SDL2 `FillRect` 改用 `SDL_memset4`，SDL2 VRAM rescale 改 32 位字访问
- BSP 与 CMake 重构：libmemfs 解耦、开机 logo 改 memfs 资产、补齐模块依赖

## 修复

- 修复 **C 代码生成 signext 缺陷**（`ret i16` 误生成为零扩展 `ori` 而非符号扩展 `addiu`）

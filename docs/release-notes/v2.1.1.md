# TCMIPS SDK v2.1.1 Release Notes

- **版本**：2.1.1

## 新功能

- 链接器新增 **memfs 目录树打包** 功能，支持将 memfs 目录树打包为镜像文件
- 模拟器新增 **JIT 解释器**，支持 jit / fast / debug 三种运行模式，支持 semihost 机制
- 模拟器新增 **GDB/LLDB 远程调试** 功能支持
- 控制台新增 **unifont 字体支持**

## 新增库

- SDL1 / SDL2 兼容层、libcg 图形库、zlib 压缩库

## 电路

- 修复 mthi / mtlo 指令 bug
